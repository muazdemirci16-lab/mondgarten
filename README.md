# Mondgarten

Ein gruseliges Rätselspiel in Tusche und Pinsel. 24 kurze Level – jeder gelöste Code lässt eine große Blüte am Mondbaum wachsen.

**Spielen:** `index.html` im Browser öffnen (oder über GitHub Pages).

**Als iPad-App:** Den Ordner `Mondgarten.swiftpm` in Swift Playgrounds öffnen und auf ▶︎ tippen.

Sprachen: Deutsch, English, Türkçe.
