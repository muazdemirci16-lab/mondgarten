# Mondgarten

Ein gruseliges Rätselspiel in Tusche und Pinsel. 24 kurze Level – jeder gelöste Code lässt eine große Blüte am Mondbaum wachsen.

**Spielen:** `index.html` im Browser öffnen (oder über GitHub Pages).

**Als iPad-App:** Den Ordner `Mondgarten.swiftpm` in Swift Playgrounds öffnen und auf ▶︎ tippen.

Sprachen: Deutsch, English, Türkçe.

## Kurzweil – Spiele gegen Langeweile

`spiele.html` öffnen: fünf kleine Spiele im selben Tusche-Stil, ebenfalls auf Deutsch, English und Türkçe.

- **Mondphasen** – gleiche Monde zusammenschieben, bis die Mondblüte aufgeht
- **Tuschepaare** – Memory mit Tuschebildern
- **Glühwurm** – Glühwürmchen in der Nacht sammeln
- **Laternen** – alle Laternen anzünden (jede schaltet ihre Nachbarn mit)
- **Nachtfalter** – durch den Bambushain flattern

Rekorde werden im Browser gespeichert. Aus dem Mondgarten-Menü führt „Mehr Spiele“ dorthin.
